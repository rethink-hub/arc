## Then listen to it

Every summary has a play button. AI Read speaks it in a natural voice, skipping ads and formatting clutter, so a long newsletter or report becomes something you can hear while driving, cooking or exercising. Condensing first and listening second cuts the reading load for people with dyslexia, ADHD or low vision. For voices, speed and pitch settings and full-screen reading, see [AI text to speech]({{ '/text-to-speech/' | relative_url }}).

Content is processed to generate summaries and speech but never stored on Arc's servers.

<h2 id="extract">Screenshot to text: pull out what you need</h2>

Sometimes you don't want a summary — you want the code, the address or the meeting link. **Smart Extract** reads the current screen and surfaces every actionable item, priority-ordered so the most urgent (an OTP about to expire, a meeting starting soon) comes first:

| Category | What it catches | One-tap action |
| --- | --- | --- |
| 📅 Event | Meeting times, appointments, schedules | Add to Calendar — a real entry, not a link |
| 🔔 Reminder | "Don't forget to..." mentions | Set Reminder — with the exact time from the text |
| ⏰ Deadline | Due dates, expiry dates, cutoffs | Create Task or Set Reminder |
| 👤 Contact | Names, phone numbers, emails | Save Contact, Call, or Send Email |
| 🎥 Meeting link | Zoom, Meet, Teams URLs buried in text | Join Meeting |
| 📍 Location | Addresses, place names | Open in Maps |
| 🔐 OTP | Verification codes | Copy Code — before it expires |

<img class="inline-phone" width="800" height="1760" src="/assets/images/screenshots/10_smart_extract_results.jpg" alt="Arc Smart Extract results on Android listing contacts, dates and links found on screen" loading="lazy" decoding="async">

### Copy text that won't select

Webview containers, locked PDFs, some messaging apps and scanned documents don't let you select text. Arc reads the screen with built-in OCR, so the words become copyable regardless of what the app allows. On desktop it works over any window — PDFs in preview apps, video subtitles, labels in design tools.

The most-used extraction is the verification code: invoke Smart Extract while it's on screen and the OTP is copied to your clipboard verbatim — no memorizing six digits while you switch apps.

### Region selection for noisy screens

A screen full of chat bubbles, sidebars and ads is noisy. Turn on **region selection** in Settings → Screenshots ("Ask for region") and Arc extracts only from the area you mark — one table row, one message, one code block.
