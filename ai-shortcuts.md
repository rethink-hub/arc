<div class="content-section">
  <h2>A shortcut that never steals your focus</h2>
  <p>The desktop Arc menu is a <strong>non-activating panel</strong>. When you press ⌃ Space it fades in over your current window, but your app keeps focus and your text cursor stays exactly where it was — macOS doesn't flip you to another Space. That's what makes <strong>AI Writer</strong> possible: Arc reads the field you're typing in and writes the result back into that same field.</p>
  <p>Close the main window and Arc keeps running — a menu-bar item on macOS, a tray icon on Windows — with the hotkey alive from any app. If ⌃ Space already belongs to Spotlight or your input method, open Settings → Activation, press Record, and pick a different combination.</p>
</div>

---

<div class="content-section">
  <h2>Keyboard-first, from summon to result</h2>
  <p>The search field is focused the moment the menu opens, with the first action selected. Type to filter, ↑ / ↓ to move, Return to run, Esc to bail out.</p>
  <p><strong>Search filters by name <em>and</em> description.</strong> Typing "summarize" finds AI Summary even though that word only appears in its subtitle. Custom actions filter in the same pass.</p>
  <p><strong>The search box doubles as a prompt box.</strong> Type a question no action matches — "what are the risks listed here?" — and press Return. Arc reads the current screen, attaches it as context, and opens a chat with your question already asked.</p>
  <p><strong>Every action can skip the menu entirely.</strong> Each row in the Arc menu carries a keyboard icon. Click it, press a combination — ⌥ S, say — and from then on that key runs the action headlessly: no menu, no panel, just the result. Arc rejects a combination that's already bound and tells you which action owns it.</p>
</div>

<div class="content-section">
  <h2>Custom AI actions: write the prompt once</h2>
  <p>Arc Actions are your own AI shortcuts. Give one a <strong>Name</strong>, a <strong>Prompt</strong>, and an icon; optionally tick <em>Capture a screenshot region</em> or <em>Enable web search</em>, and assign a keyboard shortcut. It appears in the menu immediately. Use <code>{screen_text}</code> to control where the screen content lands:</p>

<pre><code>You are a senior editor. Rewrite the following in plain English, max 120 words:

{screen_text}

Then list any claims that need a citation.</code></pre>

  <p>Omit the placeholder and the screen content is simply appended as context. Screenshot actions start with a region selector (the first capture asks for consent); web-search actions add live results — that's how "fact-check this claim" works.</p>
